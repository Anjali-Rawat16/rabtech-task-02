# Testing

## Manual Accessibility Checks

The following keyboard checks were performed on the SWTCH Energy website:

| Test | Expected / Observed Result |
|---|---|
| Tab | Focus moves forward through interactive elements. |
| Shift + Tab | Focus moves backward. |
| Enter | Links and buttons activate. |
| Space | Page scrolled during the manual check. |
